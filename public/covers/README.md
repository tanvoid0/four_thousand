# Book covers

Drop real jacket images here to show them instead of the designed fallback
covers. The filename must match the `cover.image` path in
`src/modules/registry.ts`:

- `four-thousand-weeks.jpg` — Four Thousand Weeks (Oliver Burkeman) — not bundled: publisher artwork, not ours to redistribute
- `atomic-habits.jpg` — Atomic Habits (James Clear)

If a file is missing, the app quietly falls back to a designed cover in the same
palette, so nothing breaks. Use images you have the right to redistribute.
